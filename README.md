# GoalDen
Budgeting/Investing application made with Flutter + Firebase (Backend)

GoalDen is a budgeting/savings app that can visualize the data that a user provides, and rewards them with achievements and points that can be redeemed for real world goods.
We built the frontend with Flutter and Dart, Firebase for the backend, authentication, and account handling, ElevenLabs for the sound effects, and the Gemini API for the money fact button.

# How To Setup
You will need a .env file and a service-account.json and place it into the assistant_server folder. Also make sure to run npm install inside the assistant_server folder
